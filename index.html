Kebijakan Privasi (Privacy Policy)

Selamat datang di Arka Pos Studio. Kami menghargai privasi data operasional dagang Anda.

1. Penyimpanan Data Lokal Perangkat

Seluruh data aplikasi, termasuk katalog produk, rekaman transaksi kasir, pengaturan stiker QRIS, logo, serta profil toko tersimpan sepenuhnya secara independen di memori lokal gawai Anda menggunakan enkapsulasi teknologi database *IndexedDB*. Kami sama sekali tidak mentransfer data transaksi ke server cloud pihak ketiga manapun tanpa instruksi manual Anda (misal ekspor berkas JSON).

2. Kamera & File Perangkat

Izin akses modul kamera dan file lokal hanya digunakan saat Anda melakukan pemindaian stiker statis QRIS maupun mengunggah berkas gambar logo identitas toko secara internal.
